# Comandos de Git
* **git init**: Sirve para crear un repo nuevo en la carpeta donde estas parado.
* **git clone**: Te sirve para bajarte a la compu una copia de un repo que esta en GitHub.
* **git status**: Muestra el estado del proyecto (si tocaste archivos, si agregaste algo nuevo o si tenes cosas sin guardar).
* **git add .**: Prepara todos los cambios o archivos nuevos para que queden listos para guardar.
* **git commit**: Guarda los cambios de una en la compu con un mensaje cortito de lo que hiciste.
* **git push**: Sube todo lo que guardaste en la compu directo a tu cuenta de GitHub.
## Sincronizacion
* **git pull**: Trae y baja a tu compu los cambios nuevos que subieron a GitHub.
## Ramas e historial 
* **git branch**: Te muestra las ramas del proyecto (o te crea una nueva si le mandas un nombre al final).
* **git switch**: Para cambiarte de una rama a otra al toque.
* **git merge**: Junta los cambios de una rama y los mezcla con la rama en la que estas parado.
* **git log**: Te muestra la lista con el historial de todos los commits y cambios que fuiste guardando.
